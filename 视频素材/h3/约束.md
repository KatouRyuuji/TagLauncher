# MiniMax H3 提交约束

官方模型名：`MiniMax-H3`。本包按官方 Video Generation 文档的四种模式写，**同一请求只走一种模式**。

## 模式（互斥）

| 模式 | 上传 | 本包用法 |
|---|---|---|
| 文生视频 | 只有 prompt | 本包不用 |
| 首帧 | prompt + 1 张 `role=first_frame` | C02 C04 C05 C06 C07 C09 C10 |
| 首尾帧 | prompt + `first_frame` + `last_frame` | C01 C03 C08 |
| Reference | prompt + `reference_*` | 本包不用 |

禁止在同一镜里同时出现 `first_frame` / `last_frame` 与任何 `reference_*`。`last_frame` 不能单独使用。

## 数字上限

- 时长：整数 **4–15** 秒（本包每镜已写死）
- 提示词：≤ **7000** 字
- 首尾帧图：宽高 256–5760，宽高比 2:5–5:2，单张 ≤30 MB
- 输出：建议 **2K**、**16:9**；首尾帧画幅跟输入图

## 提交方式

每一镜打开 `h3/prompts/Cxx_*.txt`：

1. 把 `【提交参数】` 填进控制台（model、duration、图片角色）
2. 把 `【提示词正文】` 整段贴进 `content[].type=text`
3. 按参数上传对应本地文件（路径相对 zip 根 `视频素材/`）

## 画面纪律

- 软件截图镜：锁定窗口铬，只允许光标、高亮、极慢推镜
- 卡片镜：汉字与图标不得变形
- 角色镜：锁死 `参考/如月有希` 与 `参考/喵星喵.png` 的脸和服装，不要换成别人
- slogan 只许出现：**现代 | 轻量 | 极速 | 标签化管理**
- C02 禁止人声，只用电报嘀嘀
